# Private project previews

Review branch: `codex/private-project-previews`. This is based on the portfolio commit that already includes Codex Meter; it does not include the unrelated CV edits from the original working directory.

## Content and imagery

Five entries in `portfolio/content/projects.json` link to static `/projects/<id>/` pages. The existing project carousel also shows their galleries. All repository URLs remain empty, rendered as “Repo · Coming soon”.

The 14 optimised WebP images total approximately 660 KB:

- Maciano: two native app captures, standard Electric voice and Dream mode.
- Keke: three native captures of quick actions, conversation and settings, using a separate temporary home directory with no real chat history.
- Consume OS / COS: three existing app smoke-test captures, dark and light home and visual trail. The trail is from a later development branch, not the available 0.2.0 release.
- Macflix: three existing documentation captures, using its staged demo library. Artwork/metadata are from TMDB.
- Trackstud: three native captures using built-in sample tasks in an isolated temporary home, showing Today, Tasks and Focus. The local demo interface differs from the 0.10.0 release.

The presentation frames crop native title bars where needed. They do not recreate application UI or invent product states. Raw native captures and temporary app copies are not committed.

## Releases

`portfolio/lib/releases.ts` is the release-page data source. The public distribution repository is https://github.com/dannkis/mac-app-releases. It contains documentation and binary assets only; the five development repositories remain private. Original application archives are mirrored unchanged, with SHA-256 manifests. Source archives, model runtimes, checkpoints and personal data are not uploaded.

Available public builds:

- `maciano-v0.1.0`
- `cos-v0.2.0`
- `trackstud-v0.10.0`

Keke remains “Download · Coming soon” because its current release is a source-only preview requiring external runtimes. Macflix remains “Download · Coming soon” because its existing THIRD_PARTY_NOTICES requires exact VLC corresponding sources and license texts before public redistribution. Its private app archive was not published.

All available builds are development previews without Apple notarisation. Pages include installation instructions, platform requirements and relevant limitations. Public source ZIPs generated by GitHub contain the distribution README, not the private application repositories.
